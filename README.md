# GameCard — магазин пополнения игровых аккаунтов (лабораторные работы N1–N3)

Учебный статический сайт магазина пополнения игровых аккаунтов:
карты PlayStation Store и Apple Gift Card, пополнение Steam по логину,
игры для PS5 (например, GTA VI).

## Как открыть

Открыть файл `index.html` в браузере (двойным щелчком). Сайт полностью статический,
сервер и база данных не нужны — товары описаны в массиве внутри `js/main.js`.

## Структура файлов

```
web/
├── index.html      — главная страница
├── catalog.html    — каталог товаров с фильтром и формой пополнения Steam
├── cart.html       — корзина и оформление заказа
├── profile.html    — профиль (раздел в разработке)
├── admin.html      — админ панель (раздел в разработке)
├── about.html      — о нас, контакты, карта проезда
├── styles.css      — все стили сайта
├── print.css       — стили версии для печати (включается кнопкой)
├── images/         — логотип и картинки товаров
└── js/
    └── main.js     — единственный скрипт: данные, каталог, корзина, печать
```

Скрипт один: он подключается на всех страницах с атрибутом `defer`, а работа
начинается после загрузки документа (`DOMContentLoaded`). Внутри четыре части:
данные, каталог, корзина, общие мелочи (печать и год в подвале).

## Что реализовано по лабораторным работам

**Лабораторная работа N1** (мини-сайт): несколько связанных страниц с общим макетом
(шапка, нижнее меню, подвал), каталог товаров с фотографиями и описанием,
страница «О нас» с показателями и контактами, карта проезда
(виджет Яндекс.Карт с адресом БГТУ), кнопка «Версия для печати».

**Лабораторная работа N2** (семантическая вёрстка): блочная вёрстка на `div` и
семантических тегах (`header`, `main`, `section`, `article`, `aside`, `footer`),
все стили вынесены в `styles.css`, названия классов и файлов — на английском,
у всех картинок заполнен `alt`, меню оформлены списками `ul`/`li`,
разные состояния ссылок (обычная, при наведении, посещённая, активная) отличаются,
кодировка UTF-8.

**Лабораторная работа N3** (динамическая страница):
- «Умный фильтр» на странице `catalog.html` без перезагрузки страницы:
  платформа, страна, номинал, цена. Значения, которые приведут к пустому результату,
  становятся недоступными (зачёркнуты и заблокированы).
- Критериев фильтрации — 4 (по заданию нужно не меньше 3).
- Товары хранятся в JS-массиве — вариант 2 из методических указаний.
- Версия для печати: кнопка переключает стилевой файл (`print.css`) без
  перезагрузки страницы, меню, фильтр и оформление скрываются.

## Пример работы фильтра

1. В фильтре выбрать платформу «PlayStation» — страны «США» и «Канада» станут недоступными.
2. Выбрать номинал «1000 INR» — в каталоге останется карта «PlayStation Store Индия 1000 INR».
3. Выбрать платформу «Steam» — вместо карточек появится форма с логином и суммой пополнения.

## Что можно улучшить дальше
